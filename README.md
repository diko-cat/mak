# Клиника «Сана» — демо-приложение

Frontend на Vite, React, TypeScript и Tailwind CSS. Данные API сейчас хранятся в `localStorage`; UI использует async-функции из `src/api`, поэтому mock-слой можно заменить сетевым клиентом без смены вызовов в компонентах.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`; локальный просмотр сборки: `npm run preview`.

## Демо-доступ

На странице входа роль выбирается карточкой, после выбора email и пароль заполняются автоматически.

| Роль | Email | Пароль |
| --- | --- | --- |
| Пациент | `patient@sana.demo` | `SanaPatient2026` |
| Врач | `doctor@sana.demo` | `SanaDoctor2026` |
| Администратор | `admin@sana.demo` | `SanaAdmin2026` |

## API mock-слой

Типы сущностей и ошибок находятся в `src/types`; async API-контракт — в `src/api/index.ts`; демо-база и её начальные данные — в `src/api/database.ts`.

Контракт включает данные клиники, врачей, услуг и пациентов; вход и демо-реквизиты; чтение, создание и смену статуса записей; свободные слоты; медицинские заключения; анализы; заявки на обратный звонок. Запись проверяет прошедшее время и пересечение с уже занятым интервалом врача. Гостевые заявки сохраняются в `localStorage`.

## Роуты

- `/` — публичная страница клиники.
- `/login` — вход и выбор демо-роли.
- `/patient` и `/patient/appointments/new` — защищённые страницы пациента.
- `/doctor/*` и `/admin/*` — защищённые точки входа в разделы врача и администратора.

Тема и сессия также сохраняются в `localStorage`.
